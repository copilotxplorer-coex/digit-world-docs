ADR-0008: Verified Work Minting
Status: Accepted

Date: 2026-11-03

Decision Type: Architecture Decision Record

Context
Digit World requires controlled currency creation.

Traditional systems generate currency through:

NPC Rewards
Daily Quests
Monster Drops
These approaches encourage inflation and farming.

Problem
The project requires a mechanism for creating Soul Digit without:

Bot Rewards
Idle Rewards
Artificial Money Generation
Decision
Digit World adopts:

Verified Work Minting
as the only approved mint source.

Mint Flow
Verified Work
        ↓
Attestation
        ↓
Checkpoint Commit
        ↓
Mint
Approved Mint Sources
Verification
Verification Tasks
Checkpoint Work
Checkpoint Processing
Checkpoint Verification
Replication Work
Replication Validation
Availability Proof
Community Projects
Verified Public Infrastructure
Prohibited Mint Sources
The following are permanently prohibited:

Monster Currency Drops

Login Rewards

Daily Rewards

Idle Uptime Rewards

Passive Resource Rewards
Budget Model
Minting uses:

Epoch Reward Budget
Example:

{
  "epoch_reward_cap": 10000
}
Distribution Formula
Reward Pool
     ×
Worker Units
     ÷
Total Units
Double Mint Prevention
Mint operations must bind to:

operation_id
checkpoint_id
authority_version
attestation_id
Duplicate minting is forbidden.

Security Requirements
Minting requires:

Trusted Verifier

Checkpoint Commit

Ledger Recording

Replay Protection
Consequences
Soul Digit creation is limited to:

Verified Useful Work
and cannot be generated by gameplay farming alone.
